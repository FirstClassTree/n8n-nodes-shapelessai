# n8n-nodes-shapelessai

[ShapelessAI](https://shapelessai.com) for [n8n](https://n8n.io): schedule and publish social media posts to X, LinkedIn, Instagram, TikTok, YouTube, Threads, Bluesky, Facebook and more from any workflow.

## Operations

- **Account > Get Many**: the connected accounts a post can go to.
- **Post > Create**: a post on one account, to its next free queue slot, at a time, or now.
- **Post > Get Many**: recent posts with status, scheduled time, live URL and error.
- **Post > Delete**: cancel a post that has not been published.

The node is usable as an AI Agent tool.

## Credentials

Make an API key at [shapelessai.com/docs/api](https://shapelessai.com/docs/api) and paste it into the **ShapelessAI API** credential. Connect your social accounts at [shapelessai.com](https://shapelessai.com) first.
